# Historical Coherence snapshots

The files in this directory were generated by `coherence-harness` v0.27.0 before Mnemion adopted `@posthog/coherence` 1.7. They are retained as historical snapshots and are not current check results.

Run `npm run coherence:spec` and `npm run coherence:run` from `mnemion-js/` for current results. `npm run coherence:scope` opens the current live reading.
